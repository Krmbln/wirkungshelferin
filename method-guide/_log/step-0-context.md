# Log step 0 – Project context & measurement frame

## Critique (draft → final)
1. **Far too thin:** about 350 words instead of 1,500–2,500. The conversation flow was just bullet points, the example empty, and the "good entry" section had no guidance per field. → Fully rewritten.
2. **Rubric not usable:** no ✓/⚠ descriptions and no source per criterion, so it could not be checked. → 8 criteria, each with ✓, ⚠ and a source.
3. **Interview not specified:** PRD F3 requires 8–12 questions when there are no documents. The draft named no order. → Interview guide with 10 questions, one per message, in a fixed order.
4. **No project boundary:** if the organisation runs several projects, it was unclear which one is measured. IMV checklist (S17, Annex I, item 1) asks for scope and boundaries. → New profile field "Projektgrenze".
5. **"Förderbericht" as intro term:** jargon without an explanation and not in the glossary. → Replaced by everyday wording; "Messrahmen" explained.
6. **Missing bridge to step 1:** the aha moment (PRD §3) needs step 1 to start from the extracted text. → The assistant notes hints on target groups/problem as "Notizen für Schritt 1" without asking about them here.
7. **"Funder-speak" pitfall unsupported:** practical knowledge, not a source claim. → Labelled as a practical tip, without a source ID.
