# Glossar – Begriffe in Klartext

> Stand: Batch C (vollständig für Schritte 0–6).
> Der Assistent erklärt Begriffe beim ersten Gebrauch mit diesen Formulierungen. Beispiele nimmt er aus dem Projekt der Person.

| Begriff | Klartext |
|---|---|
| **Annahme** | Etwas, das wahr sein muss, damit ein Schritt zum nächsten führt. |
| **Anonym / vertraulich** | Anonym: Niemand kann eine Antwort einer Person zuordnen. Vertraulich: Man weiß, wer geantwortet hat, gibt es aber nicht weiter. |
| **Ausgangswert** (Fachwort: Baseline) | Wie es vor der Veränderung war – der Vergleichspunkt. Kann auch nachträglich erfragt werden („Wie war es am Anfang?“). |
| **Auswertung** | Die Daten anschauen, vergleichen und daraus etwas ableiten – am besten bald nach der Erhebung. |
| **Außerhalb unseres Einflusses** | Eine Wirkung, für die dein Projekt selbst nichts tun kann. Ehrlich so benennen ist besser als eine Scheinverbindung. |
| **Baustein** | Das Ergebnis eines Schritts, das du bestätigst – zum Beispiel deine Zielgruppenliste. |
| **Beteiligte** (Fachwort: Stakeholder) | Personen oder Gruppen, die mit dem Projekt zu tun haben oder es beeinflussen. Zielgruppen gehören dazu, aber auch Geldgeber, Partner, Ehrenamtliche. |
| **Datenerhebungsplan** | Die Übersicht, wer welche Daten wann, wie und wofür erhebt. |
| **Datenquelle** | Wer oder was die Antwort kennt: Menschen, Listen, Unterlagen, Statistiken. |
| **Direkte Zielgruppe** | Die Menschen, auf die die Aktivitäten zielen und bei denen sich etwas verändern soll. |
| **Dominoeffekt** | Eine Veränderung folgt von selbst aus der vorherigen, ohne eigene Maßnahme. |
| **Einwilligung** | Die Zustimmung der Befragten, dass ihre Angaben genutzt werden. Bei Kindern: Einverständnis der Eltern und das Kind selbst fragen. |
| **Empfänger** | Wer die Antwort auf eine Lernfrage bekommt und nutzt – Geldgeber oder Beteiligte. |
| **Erhebung** (erheben) | Daten sammeln – durch Fragen, Beobachten, Testen oder Nachlesen. |
| **Evidenzbasis** | Woher du weißt, dass etwas stimmt. Vier Möglichkeiten: eigene Erfahrung, eigene Daten, Forschung/andere Projekte, unsicher. |
| **Externer Faktor** | Ein Einfluss, den das Projekt nicht steuern kann, der aber über den Erfolg mitentscheidet. |
| **Fokusgruppe** | Eine der 1–2 Zielgruppen, die du in der Wirkungslogik vollständig durcharbeitest. Achtung: Nicht verwechseln mit der Befragungsmethode „Fokusgruppe“ – die heißt hier Gruppengespräch. |
| **Folge** | Was passiert, wenn sich am Problem nichts ändert. |
| **Gruppengespräch** (Fachwort: Fokusgruppe als Methode) | Ein moderiertes Gespräch mit mehreren Beteiligten zu einer klaren Frage. |
| **Herausforderung** | Das gesellschaftliche Problem, zu dessen Lösung dein Projekt beitragen will – in einem Satz. |
| **Impact** | Veränderung in der Gesellschaft (Stufe 7). Ein Projekt trägt dazu bei, verursacht sie aber nie allein. |
| **Indikator** | Ein Hinweis, an dem du erkennst, ob eine Veränderung eingetreten ist. Nicht das Werkzeug, sondern das, was es misst. |
| **Indirekte Zielgruppe** | Menschen im Umfeld der direkten Zielgruppe, die zum Erfolg beitragen. |
| **Instrument** | Das Werkzeug zum Erheben: Fragebogen, Kurzabfrage, Beobachtungsbogen, Liste. |
| **Kandidat** | Eine kritische, noch unsichere Annahme oder ein Lernwunsch, über den du in Schritt 5 entscheidest: prüfen oder zurückstellen. |
| **Kernproblem** | Das zentrale Problem deiner Zielgruppe, aus ihrer Sicht beschrieben. Steht in der Mitte des Problembaums. |
| **Kritische Annahme** | Eine Annahme, ohne die das Projekt nicht funktioniert: Ist sie falsch, bricht der Pfeil – und ein wichtiges Ziel hängt allein daran. |
| **Leistung** (Fachwort: Output) | Was das Projekt anbietet und wer es nutzt (Stufen 1–3). Noch keine Wirkung. |
| **Lernfrage** | Eine Frage, die du mit deiner Messung beantworten willst – weil die Antwort etwas verändert. |
| **Lösungsbaum** | Der umgedrehte Problembaum: Aus jedem Problem wird ein erwünschter Zustand. Daraus entstehen die Wirkungsziele. |
| **Mechanismus** („weil …“) | Die Erklärung, warum ein Schritt zum nächsten führt. |
| **Messfokus** | Die 1–3 Lernfragen, auf die du deine Messung beschränkst. |
| **Messrahmen** | Wofür und für wen du Wirkung nachweisen willst, in welcher Form, und welche Daten es schon gibt. |
| **Nicht beeinflussbar** | Eine Ursache, die dein Projekt nicht ändern kann. Sie bleibt im Problembaum und wird später zum externen Faktor. |
| **Nicht-Fokusgruppe** | Eine Zielgruppe, die im Modell bleibt, aber nur mit Kernproblem und einem Ziel bearbeitet wird. |
| **Offen** | Markierung für etwas, das noch niemand weiß. Besser *offen* als geraten. |
| **Planzeile** | Eine Zeile im Datenerhebungsplan: was, woher, wie, wer, wann, wofür. Eine Zeile kann mehrere Indikatoren abdecken. |
| **Problembaum** | Ein Bild des Problems: unten die Ursachen, in der Mitte das Kernproblem, oben die Folgen. |
| **Projektgrenze** | Welches Angebot betrachtet wird – und welches nicht. Wichtig, wenn eine Organisation mehrere Angebote hat. |
| **Projektprofil** | Kurzbeschreibung deines Projekts: wer, was, wo, mit welchem Ziel. |
| **Qualitätscheck** | Prüfung deines Bausteins vor dem Bestätigen: ✓ erfüllt, ⚠ offen (Bestätigen möglich), ⛔ muss erst behoben werden. Die Kriterien heißen Rubrik. |
| **Ressourcen** (Fachwort: Input) | Was ins Projekt hineingesteckt wird: Personen, Ehrenamtliche, Geld, Räume, Material. |
| **Schwelle** | Ein Wert, unter dem ihr euren Ansatz überdenkt – statt eines Zielwerts, wenn ihr eine Annahme prüft. |
| **Unbeabsichtigte Wirkung** | Eine Veränderung, die ihr nicht geplant habt – positiv oder negativ. |
| **Ursache** | Ein Grund, warum das Problem besteht – als Zustand beschrieben, nicht als fehlendes Angebot. |
| **Verbindung** | Ein Pfeil in der Wirkungslogik – Schritt für Schritt: Aktivität → Leistung → Wirkung → höhere Wirkung. |
| **Wirkung** (Fachwort: Outcome) | Veränderung bei der Zielgruppe: Wissen und Einstellung (Stufe 4), Handeln (Stufe 5), Lebenslage (Stufe 6). |
| **Wirkungslogik** (Fachwort: Theory of Change) | Die begründete Kette von den Ressourcen über die Leistungen bis zu den Wirkungen – mit dem „weil …“ und den Annahmen dazwischen. |
| **Wirkungsnachweis** | Die nachvollziehbare Darstellung, was dein Projekt bewirkt und woher du das weißt. |
| **Wirkungstreppe** | Sieben Stufen von „Aktivitäten finden statt“ bis „Gesellschaft verändert sich“. Ab Stufe 4 spricht man von Wirkung. |
| **Wirkungsziel** | Eine Veränderung, die ihr bei der Zielgruppe erreichen wollt – so formuliert, als wäre sie schon eingetreten. |
| **Zeitrahmen** | Bis wann ein Wirkungsziel ungefähr erreicht sein soll – ein Zeitraum, kein genaues Datum. |
| **Zielgruppe** | Die Menschen, für die dein Projekt da ist und bei denen sich etwas verändern soll – direkt oder indirekt. |
| **Zielwert** | Wie viel Veränderung euch reicht – anspornend, aber erreichbar. Zu Beginn darf er geschätzt sein. |
| **Zurückgestellt** | Eine kritische Annahme oder ein Lernwunsch, den ihr bewusst (noch) nicht prüft – mit Begründung. |
